# Font Awesome 7.3.1 Pro

## ADDED

### ➕ 🎶 New Icons!
It's game on with new sports icons: `padel`, `padel-ball`, `cricket-bat`, `field-hockey-stick`, and `table-tennis-paddle`.

---

## FIXED

* 🔧 These new brand icons were introduced in 7.3.0 but were mistakenly excluded from Font Awesome Free: `visual-studio`, `dolibarr`, `obs-studio`, `storybook`, `a11y-project`, `copilot`. Those responsible have been sacked, and the icons have been freed.
* 🔧 The new `meerkat` icon in 7.3.0 somehow got a capitalized name alias of "Suricata", though all names are supposed to be lowercase.
* 🔧 Some new Slab Duo icons looked already-pressed in 7.3.0, like their Slab Press Duo counterparts: `box`, `bug`. They've been un-pressed.
* 🔧 The primary and secondary layers for the `gear` icon in Jelly Duo Regular were swapped.
* 🔧 These seal icons were redesigned and rotated: `seal`, `seal-exclamation`, `seal-question`.
