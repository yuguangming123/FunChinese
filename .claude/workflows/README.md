# .claude/workflows 工作流总览

本目录存放 FunChinese 项目的**协作流程文档**（.md）。它们定义"委派—验收"体系的固定作业流程，供主智能体在对应场景遵循执行。

> 说明：本目录当前为流程文档（非脚本）。未来若出现大规模并行任务（全库迁移、批量审查等），可在本目录添加 `.js` 工作流脚本，Claude Code 会自动识别为可复用动态工作流。

## 文档清单

| 文件 | 场景 | 用途 |
|---|---|---|
| `delegation-sop.md` | 所有委派任务 | 委派—验收标准作业流程（核心） |
| `migration-safety.md` | 数据库迁移 | Django 迁移安全流程 |
| `test-first.md` | 测试先行开发 | 先写测试再实现的流程 |

## 委派原则速览
- 主智能体**不写业务代码**，只拆需求、选角色、下发任务契约、验收决策
- 子智能体在独立上下文执行，只返回交付摘要
- 具体角色见 `.claude/agents/` 下 7 个子智能体定义
