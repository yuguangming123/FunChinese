# 审查当前改动

委派 **django-reviewer** 子智能体执行以下任务契约：

## 任务标题
只读审查当前 git diff。

## 背景
主智能体需要按项目规范验收当前工作区的未提交改动。django-reviewer 是只读审查员，绝不修改文件。

## 范围
1. 运行 `git status` 与 `git diff` 获取改动清单与内容
2. 按五维审查：编码规范（FBV/JsonResponse/DTL/app_name/中文注释）、正确性、**安全性（密钥/密码泄露专项）**、可维护性、测试覆盖
3. 按严重级别输出问题清单（严重/中等/轻微/建议），每条含「文件:行号 + 描述 + 修复建议」

## 禁止改动
- 硬性禁止任何写操作（你的权限已限制为只读）

## 交付格式
- 改动范围摘要
- 按严重级别排序的问题清单（文件:行号 + 描述 + 建议）
- 密钥/密码泄露检查结论
